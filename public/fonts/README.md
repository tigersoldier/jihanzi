# 内嵌汉字示范字体

- 字体：霞鹜文楷 GB 轻便版（LXGW WenKai GB Lite）1.522。
- 来源：[lxgw/LxgwWenkaiGB-Lite](https://github.com/lxgw/LxgwWenkaiGB-Lite)。这是上游为软件和 App 嵌入提供的轻便版。
- 许可：SIL Open Font License 1.1，完整文本见本目录的 `OFL-LXGW-WenKai-GB-Lite.txt`。允许随软件嵌入分发；字体文件不得单独售卖，衍生版本须遵守 OFL-1.1。
- 网页字体：`src/assets/fonts/lxgw-wenkai-gb-lite.woff2`。保留上游字体家族名称，仅提取 U+4E00–U+9FFF 汉字并转换为 WOFF2；未改动字形，仅用于网页显示，不作为可安装桌面字体提供。
- 覆盖范围：此 WOFF2 实际包含 18,429 个 U+4E00–U+9FFF 汉字字形。覆盖表根据字体 cmap 生成；缺字或字体加载失败时，应用会阻止显示替代字形。
- 字形定位：上游参考大陆 G 源字形和相关规范调整字形；作者仍提示它可能不适用于对规范要求极高的教材、少儿读物和字帖。本应用将其作为大字示范字体，必要时应对目标汉字逐字核对。

轻便版相较完整版省略了部分较生僻字符，超出当前字体覆盖范围的字会显示提示，不会回退到设备字体。字体用于学习卡片和字符详情中的大字，普通 UI 仍使用系统无衬线字体。
